## Rule
Primary color is Jiji green (HSL 145 60% 35%), secondary/CTA color is orange (HSL 28 95% 55%). Background is light grey (0 0% 96%) like Jiji, not warm sand.

**Why:** User explicitly asked to copy jiji.ug's UI and features.

**How to apply:** Any new pages/components should use `text-primary` for prices and green accents, `bg-secondary` for primary CTA buttons (Post Ad, Show Phone). Keep the two-row header (green bar + white category nav). Listing cards use horizontal (list) layout by default on Browse page.
